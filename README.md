# new_game_plus

Read-only mirror of **FAFF0x/gen1recomp** (new_game_plus v1.0.0), published here as a GitHub release
so sealed carts can pin it (cartkit github pins need a release + sha256sums.txt).

The release asset is the original archive, byte-for-byte; its sha256 is recorded
in the release's `sha256sums.txt`.
